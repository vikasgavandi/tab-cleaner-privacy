Tab Cleaner Privacy Policy

Last updated: September 7, 2026

Overview

Tab Cleaner is a Chrome extension that helps users manage their open browser tabs by detecting duplicate or similar tabs and restoring recently closed tabs.

Information We Process

Tab Cleaner accesses information about currently open browser tabs, such as tab titles, URLs, favicons, and tab IDs, solely to provide its tab-management features.

How Information Is Used

Tab information is processed locally in the user's browser to identify duplicate or similar tabs and allow the user to close selected tabs.

Data Collection

Tab Cleaner does not collect, sell, or share users' browsing information with third parties.

Tab Cleaner does not send users' tab information to an external server.

Data Storage

Tab Cleaner does not maintain an external database or server-side storage containing users' tab information.

Remote Code

Tab Cleaner does not download or execute remote JavaScript or other executable code.

Changes to This Policy

This privacy policy may be updated when the extension's functionality changes. Any changes will be published on this page.

Contact

If you have questions about this privacy policy, please contact the extension developer through the contact information provided on the Chrome Web Store listing.
